# Як замінити фото на сайті

| Файл | Де на сайті |
|------|-------------|
| `hero.jpg` | великий фон зверху |
| `kurs-1.jpg` | Холодне відновлення волосся |
| `kurs-2.jpg` | Ботокси-концентрати |
| `kurs-3.jpg` | Нанопластика + Кератин |
| `kurs-4.jpg` | Базовий курс |

1. Перейменуй своє фото, наприклад у `kurs-3.jpg` (можна `.jpg`, `.jpeg`, `.png` або `.webp`).
2. На GitHub відкрий папку `img` → **Add file → Upload files** → перетягни фото → **Commit changes**.
   Файл з тим самим ім'ям замінюється автоматично.
3. Якщо нове фото іншого формату (наприклад `.png`, а було `.jpg`) — видали старий файл
   (відкрий його → ⋯ → **Delete file**), інакше залишиться старе.
4. Через 1–5 хвилин онови сторінку сайту.

Порада: горизонтальне фото (приблизно 3:2), до 1 МБ. Якщо фото курсу немає — на картці показується логотип.
